# Flujo Higgsfield Unlimited - Varpal / VP

## Punto clave

El plan anual con promocion `365 Unlimited` no significa que todo lo generado desde integraciones sea ilimitado.

El uso ilimitado aplica solo cuando se genera directamente en `higgsfield.ai` y solo en los modelos que aparezcan marcados como incluidos en el plan.

No aplica a:

- API
- MCP / CLI
- Canvas
- Supercomputer
- Marketing Studio
- Shorts Studio

En esas herramientas se consumen creditos o se factura cada generacion.

## Como aprovecharlo

1. Entrar directamente en Higgsfield.
2. Ir a `Profile -> Manage Account -> Subscription -> Active unlimited models`.
3. Confirmar cuales modelos dicen `365 UNLIMITED`.
4. Generar las escenas premium dentro de esos modelos.
5. Descargar los resultados.
6. Incorporar las piezas finales a los reels, stories o posts.

## Rol de Codex / ChatGPT

Codex no debe usar MCP/API para volumen masivo de videos si el objetivo es aprovechar Unlimited.

Codex si puede preparar:

- Prompts exactos para Higgsfield web.
- Storyboards por reel.
- Lista diaria de escenas.
- Textos superpuestos sin errores.
- Captions, CTAs y hashtags.
- Revision de resultados descargados.
- Edicion posterior con textos correctos y marca.

## Flujo recomendado

1. Codex crea paquete de prompts por bloque:
   - Navidad
   - Black Friday / Cyber Monday
   - Casillero
   - Prealerta
   - Rastreo
   - Familia
   - B2B / emprendedores

2. Saul genera en Higgsfield web usando modelos `365 UNLIMITED`.

3. Saul descarga los videos o imagenes.

4. Codex:
   - Revisa calidad.
   - Recorta a 9:16, 4:5 o 1:1.
   - Agrega textos exactos.
   - Prepara portada.
   - Exporta nombres finales.
   - Sube a GitHub.

## Regla operativa

Para volumen diario:

- Higgsfield web = produccion visual masiva.
- Codex = direccion creativa, prompts, textos, control de calidad, adaptacion y organizacion.
- MCP/API = solo pruebas puntuales o casos donde valga gastar creditos.
